# Pip Marlow, Dietitian (sample concept)

A one-page website concept for a fictional health and wellness client: Pip Marlow, a non-diet dietitian and ex-pastry chef in Fremantle, WA.

Live: https://bapdagreat.github.io/hey-pip/
Moodboard and design notes: https://bapdagreat.github.io/hey-pip/moodboard.html

Static HTML, CSS and a little JS. All illustrations are hand-built SVG. Designed by Dayle Peña.
